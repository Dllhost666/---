# Задание 4 — сайт «Интерпан»

Учебный адаптивный сайт по скриншотам макета. Использованы Next.js (App Router), TypeScript, Tailwind CSS и компонентный подход. Интерфейс собран из отдельных компонентов шапки, подвала, карточек преимуществ, кейсов, новостей и каталога. Для иконок используется lucide-react; кнопки и элементы интерфейса стилизованы в духе shadcn/ui.

## Запуск

Требуется Node.js 20.9 или новее. В терминале из папки проекта выполните:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для production-сборки: `npm run build`, затем `npm run start`.

## Структура

- `app/page.tsx` — главная страница и секции сайта
- `app/globals.css` — стили и адаптивная вёрстка
- `components/site-header.tsx` — шапка и навигация
- `components/site-footer.tsx` — контактная форма и подвал
- `components/ui/button.tsx` — переиспользуемый компонент кнопки
- `components/section-heading.tsx`, `components/project-card.tsx` — вспомогательные компоненты
- `lib/utils.ts` — утилита объединения классов

Примечание: изображения и некоторые логотипы в макете представлены CSS-иллюстрациями, поэтому проект не зависит от внешних картинок. Форма контактов — демонстрационная, без отправки данных на сервер.
